# Screenshot assets

This folder holds the screenshots used by the README. None are committed yet.

## What to capture

Take each shot at 1600×1000 with the **Dark (Obsidian)** theme, a clean
workspace, and no personal data (no real API keys, file paths, or chat
contents) visible.

| File | What it must show |
|---|---|
| `chat.png` | A chat answer with the compression bar (tokens before → after, savings %) |
| `compression.png` | The before/after diff panel for a large JSON prompt |
| `project.png` | Project/IDE view: file explorer, editor, terminal |
| `agent-company.png` | Agent Company plan view and flow editor |
| `pixel-office.png` | The PixelOffice animation |
| `nucleus.png` | The Nucleus command surface |
| `settings.png` | Settings → Providers, with keys masked |

## How to use them

Add an `<img>` to the "Screenshots" section of the top-level README, for
example:

```html
<p align="center">
  <img src="docs/assets/chat.png" alt="Chat with the compression bar" width="820" />
</p>
```

Keep the images reasonably small (PNG, ≤ 300 KB each) so the repository stays
light.
