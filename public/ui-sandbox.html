UI Sandbox — öneri prototipleri

Entegrasyon öncesi onay için. Hepsi gerçek obsidian paleti ile; kod'a dokunulmadı.

1 · Sohbet başlığı türetme

Bugün: ilk mesajın ilk 22 karakteri ham hâliyle alınıyor → JSON ve kırık kelimeler başlık oluyor. Öneri: ilk satırı al, boşlukları topla, kelime sınırında 34 karaktere kes; boşsa "Yeni sohbet".

şimdi
smoke: {"users":[{"id"...
New Chat Session
--- @photo_59111706668...
def calc_data(items): ...
önerilen
smoke test — kullanıcı listesi
Yeni sohbet
foto_5911170666… (görsel)
calc_data fonksiyonu
Kural: ilk satır → fazla boşlukları tek boşluğa indir → kelime sınırında kes (≤34) → kod/JSON ise dosya-adı veya "JSON verisi" kısaltması. Elle yeniden adlandırılmışsa dokunulmaz.

2 · Token tasarruf paneli tipografisi

Bugün: "TOKEN TASARRUFU" el yazısı (Caveat) + italik serif karışımı; %0'da bile yeşil panel. Öneri: tek satır, standart UI fontu; kazanç varsa yeşil, yoksa sessiz gri tek cümle.

şimdi (%0 durumu)
TOKEN TASARRUFU
%0 azaltıldı Olduğu gibi gönderildi — bu prompt için sıkıştırma gerekmedi.
önerilen (%0 durumu)
Token tasarrufu
Olduğu gibi gönderildi — bu istekte sıkıştırma gerekmedi.
şimdi (kazançlı durum)
TOKEN TASARRUFU
%62 azaltıldı (1.246 → 473 tokens)
önerilen (kazançlı durum)
Token tasarrufu
%62 azaltıldı1.246 → 473 token
Kural: el yazısı/italik serif kalkar; tek satır, %0'da gri "olduğu gibi gönderildi", kazançta yeşil oran + token çifti. Sıkıştırma paneli bu boyutta kalır, ivye çerçeve korunur.

3 · Karşılama mesajı

Bugün: her yeni sohbetin ilk yardımcı mesajı İngilizce kalıp cümle ("Thalamus AI Assistant is ready…"). Öneri: Türkçe arayüzde Türkçe, tek satır, kullanıcı ilk mesajını yazınca kaybolur (zaten kalıcı mesaj değilse silinir).

şimdi
Thalamus AI Assistant is ready. Ask questions about your code or projects.
önerilen
Hazırım — kod sor, dosya ekle veya bir şey sor. Bu satır senin ilk mesajınla değişir.
Kural: karşılama i18n anahtarından gelir; kullanıcı ilk mesajını gönderdiğinde geçmişte kalıcı iz bırakmaz.
